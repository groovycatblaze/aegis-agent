# New Hire Onboarding Policy

## 1. Manager responsibilities
Managers must request equipment and system access for a new hire at least 5 business days before the start date by raising an IT ticket with category onboarding.

## 2. Standard onboarding kit
Every new hire receives a laptop from the tier that matches their department, a headset and a security key.

## 3. First week
New hires complete security awareness training and the code of conduct module during their first week.
